Turn AI chats into
beautiful PDFs

A one-command Python script that converts conversations from ChatGPT, Grok, Gemini, Claude, Copilot & more into clean, shareable PDFs — with syntax highlighting, tables, and dark/light themes.

Everything you need

📄

Multiple inputs

Read from a .md file, paste text, pipe from stdin, or pull directly from your clipboard.

🎨

Styled output

User & assistant messages are visually separated. Light & dark themes. Page numbers included.

⚡

Syntax highlighting

Code blocks get full Pygments syntax highlighting — Python, JS, SQL, Bash, and 500+ more languages.

📊

Tables & rich Markdown

Headings, bold, italic, nested lists, tables — all rendered faithfully via python-markdown.

🛡️

Dual rendering engines

WeasyPrint for pixel-perfect output. fpdf2 as a lightweight fallback when WeasyPrint isn't available.

🏷️

Model labels

Pass --model chatgpt (or grok, gemini, claude…) and the export header is automatically branded.

Works with every AI

🤖 ChatGPT ⚡ Grok ✨ Gemini 🧠 Claude 🛠️ Copilot 🔎 Perplexity 📝 Any Markdown

Get started in seconds

Clone the repo, install dependencies, and convert your first chat.

pip install -r requirements.txt
From a file
python ai_chat_to_pdf.py conversation.md
From clipboard
python ai_chat_to_pdf.py \ --clipboard --model grok
Custom title & dark theme
python ai_chat_to_pdf.py chat.md \ --title "My Session" \ --theme dark
Lightweight fallback
python ai_chat_to_pdf.py chat.md \ --engine fpdf
